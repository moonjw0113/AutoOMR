# AutoOMR - AI 기반 스마트 자동 채점 학습 프로그램

스마트하고 직관적인 웹 기반 문제집 정답 관리 및 OMR 답안 입력, 자동 채점 애플리케이션입니다.  
수험생, 학생, 교강사가 문제집의 정답을 등록하고 모바일이나 PC에서 OMR 마킹 방식으로 답안을 입력하면 즉시 자동 채점 및 오답 분석 리포트를 제공합니다.

---

## 1. 주요 구현 기능

### A. 홈 화면 (문제집 보관함)
- **등록된 문제집 카드 목록**: 문제집 제목, 과목 태그, 총 문제 수, 정답 등록 수 / 미등록 배지 표시
- **최근 풀이 기록 및 정답률 표시**: 최근 채점 결과 및 임시 저장된 답안 현황 실시간 확인
- **새 문제집 등록 & 샘플 문제집 자동 탑재**: 첫 실행 시 수능 국어/모의평가 샘플 문제집 자동 제공
- **문제집 관리**: 풀이 시작 (또는 이어서 풀기), 정답/정보 수정, 기존 채점 결과 보기, 삭제 (관련 기록 정리)

### B. 문제집 등록 및 편집 화면
- **문제집 정보 입력**: 문제집 이름, 과목명(국어, 수학, 영어 등), 총 문제 수(1~100개)
- **5지선다(①~⑤) 정답 설정**:
  - 각 문제별 1~5 정답 버튼 선택 (다시 누르면 정답 미등록 해제)
  - 미등록 문제 시각적 배지 알림 (채점 시 제외 안내)
- **⚡ 빠른 정답 일괄 입력 (Quick Paste)**:
  - 교재 뒤쪽 정답표의 연속 번호(`1352421345` 또는 `1,3,5,2,4...`)를 복사/붙여넣기하여 단 한 번의 클릭으로 자동 입력
- **정답 전체 초기화 및 실시간 등록 통계** 제공

### C. 답안 입력 화면 (OMR 마킹 시트)
- **직관적인 단일 문제 뷰**:
  - 현재 문제 번호 대형 표시
  - 컴퓨터용 사인펜 느낌의 ①, ②, ③, ④, ⑤ OMR 버블 마킹 버튼 (토글 해제 지원)
  - 터치 친화적 버튼 크기 (모바일 52px, 데스크톱 60px)
  - 키보드 단축키 지원: `1`~`5` 키로 답안 마킹, `←` `→` 또는 `Space` 키로 문제 이동
- **OMR 전체 시트 퀵 네비게이터 (Quick Nav)**:
  - 1번부터 N번까지 마킹 현황 그리드 표시 (마킹된 답 표시 및 미응답 표시)
  - 문제 번호 클릭 시 해당 문제로 즉시 이동
- **실시간 자동 저장 (Auto-save)**:
  - 문제를 마킹할 때마다 브라우저 로컬 스토리지에 즉시 임시 저장
  - 새로고침하거나 브라우저를 닫았다가 다시 열어도 풀던 위치와 답안 100% 복원
- **답안 초기화 및 제출 전 검토 모달**:
  - 미응답 문제 수 경고 및 미응답 번호 클릭 시 즉시 해당 문제로 이동

### D. 채점 결과 및 오답 분석 리포트
- **종합 스코어보드**:
  - 총 문제 수, 채점 가능 문제 수(정답 미등록 제외), 정답 수, 오답 수, 미응답 수, 정답률(%)
  - 정답이 0개 등록된 경우 정답률을 0%가 아닌 "-" (채점 불가 안내) 처리
- **스마트 필터링**:
  - [전체 문제 보기]
  - [🚨 오답만 모아보기]
  - [✓ 정답만 보기]
  - [미응답 보기]
  - [채점 제외 보기]
- **문제별 상세 비교 카드**:
  - 사용자 마킹 답안 vs 정답 비교 및 정답/오답/미응답/채점제외 태그
- **결과 화면에서 즉시 답안 수정 및 재채점**:
  - 결과 화면의 드롭다운에서 답안을 바로 변경하면 즉시 재채점되어 점수 갱신
  - [답안 수정하여 다시 풀기] 및 [처음부터 다시 풀기] 버튼 제공

### E. 데이터 무결성 및 동기화
- **정답 수정 시 기존 제출 기록 자동 동기화**:
  - 문제집의 정답표가 수정되면 과거 풀이 기록의 점수가 낡은 정답 기준으로 남지 않고 새 정답 기준으로 자동 재채점 동기화
- **문제집 삭제 시 연관 데이터(풀이 기록, 임시 답안) 완전 정리**

## 3. 실행 방법

별도의 서버 설치나 빌드 과정 없이 웹 브라우저에서 바로 실행할 수 있습니다.

1. 파일 탐색기에서 `d:\DEV\AutoOMR\index.html` 파일을 더블 클릭하여 실행하거나,
2. 웹 브라우저(Chrome, Edge 등) 주소창에 아래 주소를 입력하여 접속합니다:
   ```
   file:///d:/DEV/AutoOMR/index.html
   ```
3. 단위 테스트 검증 스위트 실행:
   ```
   file:///d:/DEV/AutoOMR/tests/run_tests.html
   ```

## 4. 향후 확장 로드맵 (AI & OMR 비전 인식)

현재 아키텍처는 답안 입력 방식과 채점 비즈니스 로직(`ScoringEngine.grade(workbook, userAnswers)`)이 완전히 분리되어 있어 다음 기능 추가가 용이합니다:

1. **정답지 PDF/이미지 업로드 및 OCR/AI 자동 인식**:
   - Claude/GPT Vision 또는 OCR 라이브러리를 통해 정답표 텍스트를 추출하여 `answerKey`로 자동 변환
2. **OMR 답안지 PDF 생성 및 인쇄**:
   - jsPDF 등을 활용해 문제집별 전용 OMR 마킹 시트 PDF 생성 및 인쇄
3. **스캔/카메라 촬영 OMR 마킹 자동 인식**:
   - OpenCV.js를 통한 4개 모서리(마커) 검출 및 원근 왜곡 보정(Perspective Transform)
   - 각 버블 영역의 픽셀 임계값(Thresholding) 분석으로 마킹 여부 판독 후 `ScoringEngine`으로 전달
